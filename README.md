## 🎯 نحوه استفاده

### ثبت‌نام و ورود
1. برای اولین بار، روی "ثبت‌نام کنید" کلیک کنید
2. نام و نام خانوادگی، نام کاربری و رمز عبور وارد کنید
3. بعد از ثبت‌نام، وارد شوید

### افزودن تسک
1. عنوان تسک را وارد کنید
2. درس (دسته‌بندی) را انتخاب کنید
3. اولویت را تعیین کنید
4. **تعداد ساعت مطالعه این تسک را وارد کنید**
5. "افزودن تسک" را بزنید

### انجام دادن تسک
1. روی دکمه تیک کلیک کنید
2. **ساعت تسک به آمار امروز اضافه می‌شود**
3. تسک به عنوان "انجام شده" علامت می‌خورد

### مشاهده کاربران دیگر
1. در قسمت "همه کاربران" روی هر کارت کلیک کنید
2. تسک‌ها و آمار آن کاربر را مشاهده کنید
3. **قابلیت ویرایش ندارید** (فقط مشاهده)
