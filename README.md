# 📚 سیستم مدیریت برنامه‌ریز مطالعه - نسخه 6.0 FINAL

## ✨ ویژگی‌های کامل

### 🔐 احراز هویت
- ورود/ثبت‌نام
- مدیریت Session
- پنل ادمین جداگانه

### 👥 مدیریت کاربران
- **سطح دسترسی قابل تنظیم**: ادمین می‌تونه مشاهده پروفایل دیگران رو برای هر کاربر فعال/غیرفعال کنه
- تغییر رمز توسط ادمین
- حذف کاربر
- مشاهده آمار کامل

### 📊 مدیریت دیتابیس (JSON)
- **Export**: دانلود بکاپ با تاریخ و ساعت
- **Import**: آپلود و جایگزینی (بکاپ خودکار قبل از import)
- **توجه**: ایمیل خودکار به دلیل نیاز به SMTP Server فعلاً غیرفعاله

### 📱 Progressive Web App (PWA)
- قابل نصب روی موبایل/دسکتاپ
- آیکون اختصاصی
- کار آفلاین
- تجربه مانند اپ نیتیو

### 📝 مدیریت تسک‌ها
- افزودن با درس، اولویت، ساعت، توضیحات
- ویرایش/حذف
- علامت‌گذاری انجام شده
- **تسک‌های قدیمی قابل ویرایش**: می‌تونی تسک‌های روزهای قبل رو ادیت کنی
- ساعت فقط بعد از Done به آمار اضافه میشه

### 📊 نمودارها
- هفتگی (Bar Chart)
- ماهانه (Line Chart)
- برای کاربران عادی و ادمین

### 🎨 تم روشن/تاریک
- تغییر با یک کلیک
- ذخیره برای هر کاربر

### ⏰ تاریخ و زمان
- نمایش تاریخ و ساعت فعلی در هر صفحه
- Timezone: ایران (Asia/Tehran)

### 📱 Responsive Design
- طراحی کامل موبایل
- Bootstrap 5

## ⚙️ تنظیمات ادمین

### Export/Import
- **Export**: دانلود بکاپ JSON با تاریخ
- **Import**: آپلود JSON جدید (بکاپ خودکار قبل)

### مدیریت دسترسی
- هر کاربر: دکمه تغییر دسترسی
- 🟢 فعال: می‌تونه بقیه رو ببینه
- 🔴 غیرفعال: فقط خودش

- رمز ادمین حتماً تغییر بده!
